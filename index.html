Robôs e Código

Bem-vindos à sua primeira aventura na robótica!

O que é um Robô?

Um robô não é apenas uma máquina de metal. Ele é um dispositivo que:

Sente

Usa sensores

Pensa

Usa algoritmos

Age

Faz movimentos

O que é Algoritmo?

É uma receita de bolo para o computador.

Os computadores são super rápidos, mas eles não sabem fazer nada sem um passo a passo detalhado!

1. Abra a porta do armário.
2. Pegue o cereal.
3. Coloque na tigela.

Ordem Importa!

Tente calçar os sapatos antes de colocar as meias. Dá certo? Não!

Na programação, se você inverter os passos, o robô trava ou faz bobagem.

Lógica de Programação

É como ensinamos o robô a tomar decisões usando o SE:

SE estiver chovendo ➔ PEGUE guarda-chuva.

SENÃO ➔ VÁ de camiseta.

Linguagem de Código

Os computadores só entendem eletricidade: Ligado (1) ou Desligado (0).

Como é difícil falar assim, usamos as linguagens de programação como tradutores mágicos!

01011001 01000001

Nosso Tradutor: C++

No Arduino, usamos uma linguagem chamada C++. Ela usa palavras em inglês que o computador transforma em comandos.

digitalWrite(13, HIGH); // "Ei Arduino, ligue a luz!"

O Arduino Uno

Imagine o Arduino como o Cérebro de um brinquedo inteligente.

Ele é uma placa verde cheia de caminhos elétricos onde conectamos sensores e luzes.

As Partes Dele

Porta USB

Cabo que traz o código do PC.

Chip

Onde o código fica guardado.

Pinos

Onde espetamos os fios.

Entradas e Saídas

O robô interage com o mundo de duas formas:

ENTRADA

Botões, sensores de luz e som.

SAÍDA

LEDs, motores e buzinas.

Protoboard

É o nosso "tabuleiro de ensaios". Ela serve para ligarmos os componentes sem precisar de cola ou solda.

É cheia de furinhos conectados por baixo que levam a eletricidade.

O LED

É uma lâmpada pequenininha. Mas cuidado! Ele tem lado certo: a perna maior é a positiva (+).

Se ligar invertido, ele não acende. Se ligar direto na bateria forte, ele queima!

O Resistor

Ele é o guarda-costas do LED. Ele segura o excesso de energia para o LED não explodir.

O Ciclo da Criação

1. Escrevemos o código no computador.
2. Conectamos o cabo USB.
3. Apertamos "Enviar".
4. O Arduino começa a trabalhar!

O Loop Infinito

No Arduino, existe um comando chamado LOOP. Tudo que você coloca ali dentro se repete para sempre, enquanto houver pilha!

É assim que fazemos um LED piscar sem parar.
